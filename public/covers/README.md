# Custom project covers

Drop an image here named after the repo to override its picture on the card
and its project page.

    public/covers/mste.png
    public/covers/bosif.jpg
    public/covers/penknife.webp

- Filename (minus extension) must match the repo name, case-insensitive.
- Accepted: png, jpg, jpeg, webp, gif, avif.
- Best results at a 2:1 ratio, e.g. 1200×600.
- Any repo WITHOUT a file here falls back to GitHub's auto preview image.

This README is ignored — only image files are used.
